# Print theme for Slick figures

A `ggplot2` theme for figures in reports and presentations: black text,
light grid, plain facet strips, and the legend at the bottom.

## Usage

``` r
theme_slick_print(base_size = 11, base_family = "serif")
```

## Arguments

- base_size:

  Base font size.

- base_family:

  Font family (e.g. `'serif'` for Times New Roman in Word).

## Value

A `ggplot2` theme.
